# Open Slashi from anywhere

| | macOS | Windows / Linux |
|---|---|---|
| Open Slashi | `Cmd` + `/` | `Ctrl` + `/` |
| Do with AI | `Ctrl` + `Cmd` + `/` | `Ctrl` + `Shift` + `Alt` + `/` |
| Toggle line comment (moved) | `Cmd` + `Alt` + `/` | `Ctrl` + `Alt` + `/` |

Then type `/` and a few letters:

- `/format` — format the document
- `/f readme` — find a file (Shift+Enter for rename, delete, copy path…)
- `/set font size` — change any setting
- `/test` — run your project’s test script
- `/ask why is this slow?` — ask your AI model

`Tab` completes a command so you can type its arguments, `Esc` closes.
