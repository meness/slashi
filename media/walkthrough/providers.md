# Providers

Each provider adds a family of slash commands. Turn whole providers — or single features inside them — on and off.

| Provider | Scope | Highlights |
|---|---|---|
| Files & Folders | `/f` | search, `/new`, `/mkdir`, `/rename`, `/move`, `/dup`, `/delete` |
| Navigate | `/go`, `/tab`, `/@`, `/err` | tabs, symbols, problems, `/line 42` |
| Project | `/p`, `/npm` | your scripts, package manager, frameworks & tools |
| Commands | `/cmd` | VS Code + every extension command |
| Settings | `/set` | toggle and edit any setting |
| Extensions | `/ext` | installed extensions, marketplace search & install |
| AI | `/ai` | `/ask`, `/fix`, `/edit`, `/tests`, `/commit-msg` |
| Natural language | `/do` | plain-English tasks |
| Text tools | `/tx` | case, sort, JSON, Base64, UUID… |
| Terminal | `/term` | `/run`, tasks |
| Git | `/git` | commit, push, branches, stash |
| Themes, Web, My Commands, Marketplace | `/theme`, `/web`, `/my`, `/market` | |
