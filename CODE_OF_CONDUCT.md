# Code of Conduct

Slashi follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be welcoming, be kind, assume good intent, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, discrimination, personal attacks and sharing others’ private information are not tolerated in any project space — issues, pull requests, discussions or chat.

## Reporting

Report unacceptable behavior privately by opening a [private security advisory](https://github.com/meness/slashi/security/advisories/new) marked “Code of Conduct”, or by contacting the maintainers listed on the repository. All reports are reviewed promptly and confidentially.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that violate this code, and may temporarily or permanently ban contributors for behavior they deem harmful, following the Contributor Covenant’s enforcement guidelines.
